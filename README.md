# projeto-4bim
Projeto de criação de um OA (objeto de aprendizado) para a nota final do 4º bimestre de programação no IFAL - campus Arapiraca.
O assunto escolhido para a OA foi o de eletrostática, ensinada no primeiro ano do IFAl.

## Conteúdos
### Simulador de partículas
O projeto tem um simulador de partículas, onde você pode ver seus campos elétricos e suas interações com outras partículas, com dados como força de interação entre elas, se é repulsão ou atração, etc.

### Aulas de eletrostática
O projeto também conta com algumas mini aulas de eletrostática básica, com fórmulas e explicações sobre o assunto. As aulas são divididas em 5 seções:
- Carga elétrica: sinais de carga, unidade de medida e conservação da carga num sistema isolado.
- Força eletrostática: lei de Coulomb, direção e sentido da força.
- Campo elétrico: a força aplicada em uma carga de teste.
- Potencial e energia elétrica: energia potecial e diferença de potencial.
- Trabalho para mover uma carga movimento entre A e B e conservação de energia.
